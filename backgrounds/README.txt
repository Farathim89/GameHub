BACKGROUNDS
===========
Put background images here.

- wallpaper.png is used by the "MY WALLPAPER" theme (paint 🎨 button in every game).
  Replace it with any image you like — keep the name wallpaper.png.
- To add more themes, edit themes/themes.css and themes/themes.js:
  copy one of the html[data-theme="..."] blocks in the CSS and add a matching
  entry to the THEMES list at the top of themes.js.
- Sudoku additionally has its own background picker (bottom-right) that can
  load any image file directly, e.g. background.jpg, space.jpg, nature.jpg
  placed in this folder.
